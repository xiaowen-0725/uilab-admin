# Scenario: saas-admin

通用 SaaS 管理端。

## 适合

- 多租户产品后台
- 资源管理 + 账户/外观设置 + 基础仪表盘

## 默认构成

- Shell：`inset + default + system`
- 必装：仪表盘、列表、设置、认证、错误页
- 推荐：profile / appearance

## 初始导航建议

- 概览 / 资源 / 设置

## 裁剪建议

- 去掉运营密集文案
- demo 指标可替换成业务 KPI

## Extend 常见下一步

- 资源列表（订单、成员、项目）
- billing/notification 设置段
